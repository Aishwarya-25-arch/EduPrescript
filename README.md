# EduPrescript — Student Support Dashboard

A Flask-based web application designed to help teachers monitor student academic performance and help students track their progress.

## Live Demo

**Live URL:** [Open EduPrescript]https://edu-prescript.vercel.app/student/dashboard

## Features

- Student and teacher login
- Student dashboard with academic performance details
- Teacher dashboard to view student information
- Student prescriptions and teacher notes
- Student registration
- SQLite database for local development

## Tech Stack

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- Vercel deployment

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Aishwarya-25-arch/EduPrescript.git
   cd EduPrescript
   ```

2. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Initialize the database if required:

   ```bash
   python init_db.py
   ```

4. Start the application:

   ```bash
   python app.py
   ```

5. Open `http://127.0.0.1:5000` in your browser.
